## 2. 器件功能结构

CLRD125C是双通道、双向、最高12.5 Gbps的高速信号调理器。每个方向均包含接收端CTLE和发送端驱动。

| 通道 | 输入到输出路径 | CTLE寄存器 | VGA/模式/VOD/DEM |
|---|---|---:|---|
| CH0 | S_INA0 → D_OUT0 | reg15 | 与CH1共用reg21/reg23/reg24 |
| CH1 | S_INB0 → D_OUT0 | reg22 | reg21/reg23/reg24 |
| CH2 | S_INA1 → D_OUT1 | reg29 | 与CH3共用reg35/reg37/reg38 |
| CH3 | S_INB1 → D_OUT1 | reg36 | reg35/reg37/reg38 |
| CH4 | D_IN0 → S_OUTA0 | reg44 | reg43/reg45/reg46 |
| CH5 | D_IN0 → S_OUTB0 | reg51 | reg43/reg52/reg53 |
| CH6 | D_IN1 → S_OUTA1 | reg58 | reg57/reg59/reg60 |
| CH7 | D_IN1 → S_OUTB1 | reg65 | reg57/reg66/reg67 |

需要特别注意：

- CH0/CH1共用D_OUT0，CH2/CH3共用D_OUT1；
- CH4和CH5虽然输入都来自D_IN0，但分别驱动S_OUTA0和S_OUTB0；
- CH6和CH7虽然输入都来自D_IN1，但分别驱动S_OUTA1和S_OUTB1；
- CTLE针对输入路径损耗，VOD/DEM针对输出路径损耗。

## 3. 三种控制方式

### 3.1 引脚模式

`ENSMB`通过1 kΩ接地。EQ、MODE、SEL和INPUT_EN由四级输入引脚决定。

适合固定配置，但挡位有限，不利于逐通道调试。

### 3.2 SMBus从机模式

`ENSMB`通过1 kΩ接VDD。MCU通过SMBus/I²C写寄存器。

这是本工程推荐的方式，优点是：

- 每个通道可以独立设置CTLE；
- 可以回读寄存器确认配置；
- 可以根据眼图和误码率逐级调整；
- 以后修改走线或速率不需要改硬件电阻。

### 3.3 EEPROM主机模式

`ENSMB`悬空，由CLRD125C上电读取外部EEPROM。

适合量产后配置固定、无需MCU参与的产品，不适合当前调试阶段。

## 4. I²C地址和寄存器地址

手册中地址字节`0xB0`包含最低位的读写位：

- 写地址字节：`0xB0`
- 读地址字节：`0xB1`
- 对应7位I²C地址：`0x58`

手册按标准换算得到7位地址`0x58`。当前驱动以V1.0标准地址范围
`0x58~0x67`为正式探测范围，并额外保留一次早期工程`0x30`兼容探测：

```c
#define CLRD125C_DEVICE_ADDR_LEGACY  0x30U
#define CLRD125C_DEVICE_ADDR_V1_MIN  0x58U
#define CLRD125C_DEVICE_ADDR_V1_MAX  0x67U
#define CLRD125C_REG_WIRE_BASE  0x00U
```

由于`gpioI2cRead/gpioI2cWrite`会将7位地址左移，标准地址`0x58`
对应线上写/读地址`0xB0/0xB1`。

这里仍存在需要通过硬件波形确认的资料差异：

- V1.0手册描述：7位地址`0x58`，寄存器地址增加`0x80`；
- 早期工程曾使用`0x30`兼容地址并直接发送寄存器偏移。

驱动通过地址范围宏和`CLRD125C_REG_WIRE_BASE`集中管理这些差异。
最终配置必须以逻辑分析仪的ACK结果、ENSMB电平和AD[3:0]硬件接法为准。

## 5. 推荐的软件配置方式

推荐采用“配置描述表 + 掩码读改写 + 回读校验”：

```c
typedef struct
{
    uint8_t reg;
    uint8_t mask;
    uint8_t value;
} CLRD125_CFG;
```

每一次配置执行：

1. 读原寄存器；
2. `new = (old & ~mask) | (value & mask)`；
3. 写新值；
4. 重新读取；
5. 比较掩码覆盖的位；
6. 失败时记录寄存器、期望值和实测值。

不建议直接整字节覆盖包含保留位、短路保护位或状态位的寄存器。

推荐初始化顺序：

1. 上电后等待至少500 ms；
2. 扫描并确认I²C地址有ACK；
3. 配置reg6、reg8，让EQ/VGA/DEM/MODE/EN_HF由寄存器控制；
4. 配置reg78和reg79，确定路由与Fanout；
5. 配置reg1，启用需要的通道；
6. 设置线性或非线性模式；
7. 设置EN_HF；
8. 设置CTLE；
9. 在线性模式下设置VGA，或在非线性模式下设置VOD/DEM；
10. 回读所有配置寄存器；
11. 读取RX Detect和LOS状态；
12. 通过眼图、误码率和链路训练结果微调。

## 6. 参数应该根据什么计算

### 6.1 先确定工作速率和奈奎斯特频率

对于NRZ信号：

```text
奈奎斯特频率 fN = 数据速率 / 2
```

示例：

| 数据速率 | 奈奎斯特频率 |
|---:|---:|
| 6 Gbps | 3 GHz |
| 8 Gbps | 4 GHz |
| 10.3125 Gbps | 5.15625 GHz |
| 12.5 Gbps | 6.25 GHz |

CLRD125C手册中的CTLE表主要给出6.25 GHz下的增益，最直接对应12.5 Gbps NRZ。低速链路不能只机械照搬6.25 GHz数值，应结合实际插损曲线和眼图调整。

### 6.2 计算输入侧总插入损耗

每条输入路径单独计算：

```text
IL_RX(fN) =
    输入PCB走线损耗
  + 连接器损耗
  + 过孔及残桩损耗
  + 线缆损耗
  + 其他无源器件损耗
```

最好使用以下数据，优先级从高到低：

1. VNA实测S参数；
2. PCB/连接器厂商提供的S参数；
3. SI仿真结果；
4. 按板材、线宽、长度进行的经验估算。

### 6.3 选择CTLE初始值

CTLE用于补偿输入路径的高频衰减。初始选择原则：

```text
CTLE增益 ≈ 输入路径在奈奎斯特频率附近的插入损耗
```

建议初始值比理论损耗低1～3 dB，避免过均衡放大高频噪声和串扰，再逐级向上调整。

判断方向：

- 眼图上下幅度尚可，但边沿慢、水平眼闭合：适当增加CTLE；
- 高频噪声、过冲、振铃明显：降低CTLE；
- 误码率随CTLE增加先下降后上升：选择误码率最低附近的挡位；
- 四条路径损耗不同：必须分别设置，不要统一写同一个code。

### 6.4 EN_HF与CTLE Code

CLRD125C V1.0的CTLE为5位：

```text
reg15/22/29/36/44/51/58/65[4:0] = CTLE code 0x00～0x1F
```

reg7中的每一位控制相应通道的EN_HF：

```text
reg7[0] → CH0
...
reg7[7] → CH7
```

手册给出的典型关系：

| EN_HF | Code范围 | 6.25 GHz典型补偿范围 |
|---:|---:|---:|
| 0 | 0x00～0x1F | 0.3～18.5 dB |
| 1 | 0x00～0x1F | 9.7～28.8 dB |

常用参考点：

| EN_HF | Code | 约等于 |
|---:|---:|---:|
| 0 | 0x0A | 8.9 dB |
| 0 | 0x0F | 11.8 dB |
| 0 | 0x16 | 15.3 dB |
| 0 | 0x1F | 18.5 dB |
| 1 | 0x07 | 15.9 dB |
| 1 | 0x09 | 17.7 dB |
| 1 | 0x0F | 21.5 dB |
| 1 | 0x1F | 28.8 dB |

当输入损耗小于约15 dB时，优先使用`EN_HF=0`；损耗超过约15 dB或使用非线性模式时，按照厂商调试建议使用`EN_HF=1`。

### 6.5 线性模式下的VGA

`mode_chx=0`时为线性模式，VOD和DEM调节被禁用，输出幅度可通过VGA微调。

VGA挡位：

| Code | 增益 |
|---:|---:|
| 00 | −2 dB |
| 01 | −1 dB |
| 10 | +0.5 dB |
| 11 | +1.5 dB |

推荐先使用默认`+0.5 dB`，只有在接收端幅度不足或过大时再调整。

### 6.6 非线性模式下的VOD

`mode_chx=1`时可设置VOD和DEM。

| VOD code | 标称VOD |
|---:|---:|
| 000 | 0.6 V |
| 001 | 0.7 V |
| 010 | 0.8 V |
| 011 | 0.9 V |
| 100 | 1.0 V |
| 101 | 1.1 V |
| 110 | 1.2 V |
| 111 | 1.26 V |

VOD不是根据PCB损耗简单相加计算，而是根据接收端需要的幅度范围选择：

```text
预计接收幅度 ≈ 发射VOD × 10^(-输出路径插损/20)
```

该公式只适合作为初步估算，因为高速接收质量还受反射、抖动、去加重和接收端均衡影响。

推荐步骤：

1. 从0.8 V或1.0 V开始；
2. 确认接收端不会过驱；
3. 若垂直眼高不足，再逐级提高；
4. 若功耗、串扰、过冲明显，则降低。

### 6.7 非线性模式下的DEM

DEM主要补偿CLRD125C输出到下一级接收器之间的高频损耗。

| DEM code | 典型去加重 |
|---:|---:|
| 000 | −1.5 dB |
| 001 | −3.5 dB |
| 010 | −5 dB |
| 011 | −7 dB |
| 100 | −7.9 dB |
| 101 | −9.5 dB |
| 110 | −10.9 dB |

厂商建议优先使用`000`或`001`。只有输出路径确实较长，并通过眼图或误码率确认有效时，才继续增加。

DEM选择依据是输出路径在低频与奈奎斯特频率之间的损耗差，而不是整条链路的绝对损耗：

```text
目标DEM ≈ IL_TX(fN) - IL_TX(低频参考点)
```

实际配置应选择最接近但不过补偿的挡位。

## 7. 与当前LT1258等效的初始配置

当前LT1258效果：

- SRXB0、SRXB1、DRXA0、DRXA1输入路径；
- CTLE约17.6 dB；
- DTXB0、DTXB1、STXA0、STXA1输出；
- VOD约0.8 Vp-p；
- DEM约−4.4 dB；
- 输入输出持续使能、50 Ω端接；
- 不开启Fanout。

CLRD125C对应路径：

| LT1258路径 | CLRD125C路径 |
|---|---|
| SRXB0 → DTXB0 | S_INB0 → D_OUT0，CH1 |
| SRXB1 → DTXB1 | S_INB1 → D_OUT1，CH3 |
| DRXA0 → STXA0 | D_IN0 → S_OUTA0，CH4 |
| DRXA1 → STXA1 | D_IN1 → S_OUTA1，CH6 |

### 7.1 基础控制和路由

| 寄存器 | 写入值 | 含义 |
|---:|---:|---|
| reg6 | 0xE0 | EQ、VGA、DEM由寄存器控制 |
| reg8 | 0x0C | MODE、EN_HF由寄存器控制 |
| reg78 | 0x07 | INPUT_EN、SEL0、SEL1由寄存器控制 |
| reg1 | 0x00 | 所有通道开启 |
| reg79 | 0x50 | SEL1=01、SEL0=01、INPUT_EN=00 |

`reg79=0x50`实现：

- S_INB0 → D_OUT0；
- S_INB1 → D_OUT1；
- D_IN0 → S_OUTA0；
- D_IN1 → S_OUTA1；
- S_OUTB0/S_OUTB1不参与当前路径；
- Fanout关闭。

### 7.2 CTLE

有效输入通道为CH1、CH3、CH4、CH6：

```text
reg7 = BIT1 | BIT3 | BIT4 | BIT6 = 0x5A
```

在`EN_HF=1`时，CTLE code `0x09`约为17.7 dB，最接近LT1258的17.6 dB：

| 通道 | 寄存器 | Code |
|---|---:|---:|
| CH1/S_INB0 | reg22 | 0x09 |
| CH3/S_INB1 | reg36 | 0x09 |
| CH4/D_IN0 | reg44 | 0x09 |
| CH6/D_IN1 | reg58 | 0x09 |

写CTLE时掩码必须为`0x1F`。

### 7.3 模式、VOD和DEM

为了接近LT1258的0.8 V、−4.4 dB，需要采用非线性模式：

- `mode=1`
- `VOD code=010`，约0.8 V
- `DEM code=010`，约−5 dB

CLRD125C没有精确−4.4 dB挡位，−5 dB是最近值。上板后也可以对比−3.5 dB。

| 输出 | 模式/VOD寄存器 | DEM寄存器 |
|---|---:|---:|
| D_OUT0 | reg23 | reg24 |
| D_OUT1 | reg37 | reg38 |
| S_OUTA0 | reg45 | reg46 |
| S_OUTA1 | reg59 | reg60 |

模式/VOD寄存器应使用读改写：

```c
/* bit6=mode，bit2:0=VOD；保留SCP和保留位。 */
value = (oldValue & (uint8_t)(~0x47U)) | 0x42U;
```

DEM寄存器：

```c
value = (oldValue & (uint8_t)(~0x07U)) | 0x02U;
```

## 8. 上板调试流程

### 8.1 第一步：只验证通信

1. 确认ENSMB为SMBus从机模式；
2. 上电等待500 ms；
3. 用示波器或逻辑分析仪观察SCL/SDA；
4. 先测试当前板卡历史地址0x30；若无ACK，再测试0x58；
5. 读取几个有确定默认值的寄存器；
6. 不再使用旧版`reg0x44=0x55`作为Device ID判断。

### 8.2 第二步：验证路由

暂时使用较低CTLE和较弱DEM：

1. 写reg6/reg8/reg78；
2. 写reg79=0x50；
3. 确认四条预期路径均有输出；
4. 确认S_OUTB0/S_OUTB1没有被错误开启为Fanout。

### 8.3 第三步：调CTLE

每条路径单独操作：

1. 从根据插损估算的较低挡开始；
2. 每次只增加一级；
3. 记录眼高、眼宽、总抖动和误码率；
4. 找到性能最佳点；
5. 从最佳点回退一级作为量产裕量候选；
6. 在高低温、电压上下限重新验证。

### 8.4 第四步：调VOD和DEM

1. 固定已经选好的CTLE；
2. VOD从0.8 V开始；
3. DEM比较−3.5 dB和−5 dB；
4. 输出路径较短时优先较小DEM；
5. 输出路径较长时再增加DEM；
6. 每次只改变一个参数，避免无法判断改善来源。

### 8.5 建议记录表

每次实验至少记录：

| 项目 | 内容 |
|---|---|
| PCB版本 | 板卡和走线版本 |
| 通道 | CH0～CH7 |
| 数据速率 | Gbps |
| 输入路径估算损耗 | dB@奈奎斯特频率 |
| 输出路径估算损耗 | dB@奈奎斯特频率 |
| EN_HF | 0/1 |
| CTLE Code | 0x00～0x1F |
| Mode | 线性/非线性 |
| VGA或VOD | Code和标称值 |
| DEM | Code和标称值 |
| 眼高/眼宽 | 实测 |
| 总抖动 | 实测 |
| BER | 实测 |
| 温度/电压 | 测试条件 |

## 9. 常见错误

1. 将手册的`0xB0`直接作为7位地址传给当前I²C驱动；
2. 继续使用旧版CLRD125的`0x30`地址；
3. 继续读取reg0x44并期待Device ID 0x55；
4. 将CTLE掩码写成0x0F，遗漏第5位；
5. 写了VOD/DEM，但`mode_chx`仍为0，导致设置不生效；
6. 使用非线性模式却没有打开对应EN_HF；
7. 没有写reg6/reg8，配置仍被外部引脚覆盖；
8. 整字节覆盖含保留位的寄存器；
9. 所有通道使用同一个CTLE，不考虑实际走线差异；
10. 只看是否能够连通，不检查眼图、误码率和温度裕量。

## 10. 推荐的量产策略

调试阶段采用MCU SMBus配置，并保留串口输出和寄存器回读。

参数确定后：

1. 将每个PCB版本的参数保存成独立配置表；
2. 配置表增加版本号和校验值；
3. 上电配置后进行回读；
4. 任一关键寄存器不一致时报告初始化失败；
5. 保留一套保守参数作为故障回退配置；
6. 完成多板、温度、电压和批次验证后，再决定是否转为EEPROM自动加载。
