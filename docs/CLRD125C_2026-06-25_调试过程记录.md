## 4. 完整 80 字节配置表写入与回读

CLRD125C V1.0 的 SMBus 寄存器地址从 `0x80` 开始。

代码中使用：

```text
D[n] -> 线上寄存器地址 0x80 + n
D[0]~D[79] -> 0x80~0xCF
```

当前程序会对 4 片芯片执行相同流程：

```text
选择芯片地址
  -> 地址 probe
  -> 写入完整 D[0]~D[79]
  -> 回读完整 D[0]~D[79]
  -> 逐项比较
  -> 打印关键配置项和 summary
```

今日验证结果：

```text
write_fail = 0
read_fail  = 0
verify_diff = 0
verify_warn = 12
CLRD125C = OK(SMBUS)
```

其中每片有 3 个允许的回读差异：

| D 下标 | 线上寄存器 | 现象 | 处理 |
| --- | --- | --- | --- |
| D[0] | 0x80 | 回读值随芯片地址变化 | WARN，不判失败 |
| D[69] | 0xC5 | 写 0xAA 后读回 0x5A | WARN，不判失败 |
| D[70] | 0xC6 | 写 0xA0 后读回 0xA5 | WARN，不判失败 |

这些寄存器属于地址/状态类寄存器，不作为配置失败依据。

## 5. 当前 LT1258 等效配置

## 6. 为什么使用 CH1 / CH3 / CH4 / CH6

选择 CH1、CH3、CH4、CH6 是为了对应原 LT1258 板上的实际高速链路。

当前等效映射为：

| 原 LT1258 链路 | CLRD125C 通道 |
| --- | --- |
| S_INB0 -> D_OUT0 | CH1 |
| S_INB1 -> D_OUT1 | CH3 |
| D_IN0 -> S_OUTA0 | CH4 |
| D_IN1 -> S_OUTA1 | CH6 |

因此 `D[7] = 0x5A`：

```text
0x5A = 0101 1010b
bit1 = CH1
bit3 = CH3
bit4 = CH4
bit6 = CH6
```

即只开启这 4 条实际使用链路的高频增强。

## 7. 串口打印优化

## 8. Keil 编译问题与处理

今日 Keil ARMCC V5 编译时报错：

```text
invalid multibyte character sequence
missing closing quote
expected a ","
```

原因：

代码中的串口打印字符串包含中文，ARMCC V5 对当前源码编码解析异常，导致中文字符串被破坏，进而造成字符串引号识别错误。

处理：

- 保留中文注释。
- 将用于运行时打印的字符串全部改成英文 ASCII。

修复后，`clrd125c_v1.c` 中不再存在中文字符串字面量。

## 4. 板级 LOS 与 CLRD125C 内部 LOS 的含义

当前增加了 5 秒一次的链路状态打印。

示例：

```text
[LINK-STAT] LOS_val[7:0]=11110011 LOS=0xF3 SFP_OK[7:0]=00001100  note: SFP_OK=1 means board LOS pin is 0
[CLRD125C-CH] dev1 0x5C reg70=0xFF CH[7:0]=11111111 focus(CH1=1 CH3=1 CH4=1 CH6=1)
```

含义如下：

| 字段 | 含义 | 极性 |
| --- | --- | --- |
| `LOS_val[7:0]` | MCU 读取到的板级 SFP LOS 原始值 | 0 表示该 SFP 有光/OK，1 表示 LOS |
| `SFP_OK[7:0]` | 对 `LOS_val` 取反后的直观显示 | 1 表示该 SFP 有光/OK |
| `reg70` | CLRD125C 的 D[70]/0xC6，内部 `det_losb<7:0>` | 1 通常表示该通道检测到信号/OK，0 通常表示 LOS |
| `CH[7:0]` | 按 CH7 到 CH0 展示 `reg70` 的每一位 | 1 通常表示通道 OK |
| `focus(...)` | 当前重点关注的有效通道 | 当前重点看 CH1/CH3/CH4/CH6 |

注意：板级 LOS 与 CLRD125C 内部 `losb` 的极性相反。

```text
板级 LOS：0 = OK，1 = LOS
CLRD125C losb：1 = OK，0 = LOS
```

## 5. 今日确认到的 SFP 与 CLRD125C 通道关系

通过插拔/回环观察，当前初步确认：

| 板级端口 | 对应 CLRD125C | 对应内部通道 | 依据 |
| --- | --- | --- | --- |
| SFP2 | dev1 / 0x5C | CH4 | SFP2 OK 时，dev1 的 CH4 变为 1 |
| SFP3 | dev1 / 0x5C | CH6 | SFP3 OK 时，dev1 的 CH6 变为 1 |

回环插入后的典型日志：

```text
[LINK-STAT] LOS_val[7:0]=11110011 LOS=0xF3 SFP_OK[7:0]=00001100
[CLRD125C-CH] dev0 0x58 reg70=0xA5 CH[7:0]=10100101 focus(CH1=0 CH3=0 CH4=0 CH6=0)
[CLRD125C-CH] dev1 0x5C reg70=0xFF CH[7:0]=11111111 focus(CH1=1 CH3=1 CH4=1 CH6=1)
[CLRD125C-CH] dev2 0x60 reg70=0xA5 CH[7:0]=10100101 focus(CH1=0 CH3=0 CH4=0 CH6=0)
[CLRD125C-CH] dev3 0x64 reg70=0xA5 CH[7:0]=10100101 focus(CH1=0 CH3=0 CH4=0 CH6=0)
```

从该日志看：

1. `SFP_OK[7:0]=00001100`，说明 SFP2/SFP3 有光。
2. dev1 的 `reg70=0xFF`，说明该芯片内部 8 个 LOSB 位全部为 1。
3. 当前实际链路重点应该先围绕 dev1 的 CH4/CH6 调整。
